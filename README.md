# Mark Kentwell's open skills

Skills I use every day, cleaned up and shared publicly. They work in Claude (Claude Code, Cowork and claude.ai), and the ideas carry over to ChatGPT, Codex and Gemini.

| Skill | What it does |
|---|---|
| [model-router](model-router/SKILL.md) | Routes every piece of AI work to the cheapest model and lowest effort that can do it well, sized to how urgent the job is. Covers Claude's model tiers and maps them to ChatGPT, Gemini and Grok. |
| [pdf-auto-convert](pdf-auto-convert/SKILL.md) | Converts PDFs to clean Markdown before the AI reads them: a fraction of the tokens, better understanding. |

## Install

- **Claude Code:** copy a skill folder into `~/.claude/skills/`, so you end up with `~/.claude/skills/model-router/SKILL.md`.
- **claude.ai:** zip the skill folder, then go to Settings → Capabilities → Skills and upload it.
- **Other tools:** paste the SKILL.md into your project or custom instructions.

**Read every skill before you install it.** A skill is a set of instructions your AI will follow, so know what it says.
